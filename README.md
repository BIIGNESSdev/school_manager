# School Manager - TP2/TP3

Projet Django de gestion des etudiants realise par Seynabou - Dakar.

## Description
Application web permettant de gerer les etudiants d'une ecole :
- Page d'accueil
- Liste des etudiants (2 etudiants de test)
- Detail d'un etudiant
- Ajout via formulaire (TP3)
- Recherche et suppression (TP3)
- Admin Django

## Prerequis
- Python 3.10+
- Git
- Windows 10/11
